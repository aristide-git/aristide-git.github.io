OthelAI — Jeu Othello avec IA

Développement d'un jeu Othello multijoueur en ligne avec backend Flask et intelligence artificielle implémentée en C pour l'adversaire.

Technologies

JavaScript Flask Python C WebSockets

Fonctionnalités

  • Interface de jeu interactive en JavaScript
  • Multijoueur en temps réel avec WebSockets
  • IA avancée développée en C pour l'adversaire
  • Backend Flask pour la gestion des parties

Défis techniques

  • Implémentation de l'algorithme minimax pour l'IA
  • Gestion des communications temps réel
  • Intégration C/Python pour optimiser les performances

💡 Retours d'expérience & Compétences acquises

Travail d'équipe & Protocoles : Ce projet m'a appris à collaborer avec un groupe aléatoire et à définir un protocole de communication strict. Chaque groupe développait sa propre IA, mais toutes devaient pouvoir s'affronter : le respect des spécifications d'interface était donc critique (plus que le code lui-même).

Python vs C : J'ai touché du doigt le compromis performance/simplicité. Python gérait la logique de jeu et le serveur (simplicité), tandis que le moteur d'IA a été écrit en C pour maximiser la profondeur de recherche de l'algorithme Minimax dans le temps imparti.

Réalité du terrain : Le passage d'un environnement local (rapide, stable) à un déploiement réel a révélé des problèmes inattendus (latence réseau, timeouts) qu'il a fallu gérer pour éviter les crashs en plein match.
