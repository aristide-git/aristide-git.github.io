Dashboard Temps Réel pour Mobilité Services

Création d'un dashboard en temps réel avec Apache Superset, orchestré par Airflow et alimenté par PostgreSQL pour le suivi des indicateurs de performance.

Technologies

Apache Superset Apache Airflow PostgreSQL Python Docker Nginx

Objectifs

  • Automatiser les pipelines de données avec Airflow
  • Créer des dashboards partagés avec Superset
  • Assurer la mise à jour en temps réel des données
  • Centraliser les KPI de Mobilité Services

Architecture

  • ETL automatisé avec Apache Airflow
  • Stockage des données dans PostgreSQL
  • Visualisation interactive avec Superset
  • Déploiement conteneurisé avec Docker

Résultats

  • Réduction du temps de traitement de 40%
  • Amélioration de la qualité des données
  • Dashboards accessibles 24/7
  • Automatisation complète du processus
