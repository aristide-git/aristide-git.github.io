Comparaison de Modèles de Prévision Météo

Étude comparative de plusieurs modèles de machine learning pour la prévision météo de Paris, en utilisant les données publiques de data.gouv.fr.

Technologies

Python Scikit-learn Pandas NumPy Matplotlib Seaborn

Approche méthodologique

  • Collecte et nettoyage des données météorologiques
  • Feature engineering et sélection des variables
  • Comparaison de modèles (Random Forest, XGBoost, SVM)
  • Validation croisée et évaluation des performances

Modèles comparés

  • Random Forest Regressor
  • XGBoost
  • Support Vector Machine
  • Régression linéaire multiple

Métriques d'évaluation

  • Mean Absolute Error (MAE)
  • Root Mean Square Error (RMSE)
  • R² Score
  • Analyse des résidus

Résultats

  • Identification du meilleur modèle pour la prévision
  • Analyse des features les plus importantes
  • Visualisations des prédictions vs réalité
