Dashboard Data Analytics

Création d'un tableau de bord interactif (Superset) pour la visualisation des données en temps réel, déployé dans un environnement conteneurisé et orchestré.

Technologies

Python Pandas Superset Docker Apache Airflow Nginx PostgreSQL MariaDB

Objectifs

  • Automatiser les pipelines de données (Airflow)
  • Exposer des dashboards partagés (Superset)
  • Normaliser les schémas de données (SQL)

Résultats

  • Réduction du temps de traitement de 40%
  • Amélioration de la qualité et de la fiabilité des données
