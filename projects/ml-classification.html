Modèle de Classification (Prévision météo)

Développement d'un modèle de classification basé sur des données publiques (data.gouv.fr) pour la prévision d'événements météo.

Technologies

Scikit-learn TensorFlow NumPy Pandas

Approche

  • Nettoyage et feature engineering
  • Comparaison de plusieurs modèles (RF, XGBoost, NN)
  • Validation croisée et métriques (F1, ROC AUC)
